# contributing
thanks for having interest in contributing to this repo <3

anyways, here's a guide to ensure your submissions (done through Pull Requests) will work smoothly with the repo's standards!

## repository structure
all game addition contributions should be added to [discord-orbs-games/](./discord-orbs-games/)

```text
discord-orbs-games/ (main directory)
└─ <game-name>/
    └─ <binaries>/ (game-specific)
        └─ <executable-name>.exe
```

## contribution rules
1. **executable binary**:
   - all contributions **must** use `7zG.exe` as its main executable (`<executable-name.exe`).
   - submissions using a different executable or otherwise any non-executable file format will be auto-rejected for user privacy and safety.
2. **functionality**:
   - all contributions are expected to have tested their folder structure before submission.
   - your submission may be fixed if the executable naming is wrong, or may be rejected if the folder structure names use cryptid unicode or otherwise more than 50% of the structure does not match.
3. **folders & files**:
   - all contributions are expected to only contain the folder path for the game's executable.
   - consideration may be applied where unnecessary files and folders will be purged before your submission gets pushed.

### checklist (for submitters)!
1. game folder follows structure convention
2. executable is `7zG.exe`
3. folders are properly strcutured
4. tested locally to ensure stability
